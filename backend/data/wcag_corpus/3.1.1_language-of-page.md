# 3.1.1 Language of Page (Level A)

Canonical URL: https://www.w3.org/WAI/WCAG22/Understanding/language-of-page.html

The default human language of each web page can be programmatically
determined.

## Why it matters

Screen readers use the language attribute to pick the correct voice,
pronunciation rules, and hyphenation. Without it, English text might be read
with a French accent or vice versa — harming comprehension.

## Common failures

- `<html>` with no `lang` attribute.
- Incorrect language code (e.g. `lang="english"`).
- Multilingual page where embedded sections are not marked with their own
  `lang` attribute.

## Fix guidance

- Set `<html lang="en">` (or the correct BCP 47 tag).
- For quoted or embedded foreign-language passages, wrap in an element with
  the correct `lang`, e.g. `<span lang="fr">bonjour</span>`.
