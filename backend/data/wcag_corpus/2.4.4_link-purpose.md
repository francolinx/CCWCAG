# 2.4.4 Link Purpose (In Context) (Level A)

Canonical URL: https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html

The purpose of each link can be determined from the link text alone, or from
the link text together with its programmatically determined link context.

## Why it matters

Screen reader users often navigate by pulling up a list of links. Links
labeled "click here" or "read more" are meaningless out of context. Empty
links (icon-only social buttons) are invisible to assistive technology.

## Common failures

- `<a>` elements with no text and no `aria-label`.
- Links reading only "click here" / "read more".
- Icon-only links (social icons, cart icon) with no accessible name.
- Multiple links with identical text leading to different URLs.

## Fix guidance

- Write link text that is meaningful out of context: "Download the 2024
  accessibility report (PDF)".
- For icon-only links, add `aria-label` or visually-hidden text.
- Avoid "click here". Make the action verb + object part of the link text.

## Related techniques

- H30: Providing link text that describes the purpose of a link.
- ARIA7 / ARIA8: Using aria-labelledby / aria-label for link purpose.
