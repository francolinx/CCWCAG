# 2.4.7 Focus Visible (Level AA)

Canonical URL: https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html

Any keyboard-operable user interface has a mode of operation where the
keyboard focus indicator is visible.

## Why it matters

Without a visible focus indicator, keyboard users literally cannot see where
they are on the page. Many themes disable the default outline (`outline:
none`) without providing a replacement.

## Common failures

- Global `*:focus { outline: none }` with no replacement.
- Focus ring with contrast below 3:1.
- Focus indicator hidden behind another element (z-index issues).

## Fix guidance

- Never remove the focus ring without replacing it with an equally visible
  alternative.
- Use `:focus-visible` to show a ring for keyboard users only if you want to
  avoid the ring on mouse click.
- Aim for a visible outline with at least 3:1 contrast against the adjacent
  colors.
