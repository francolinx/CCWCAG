# WCAG Corpus Sources

All knowledge-base entries in this directory are derived from material
published by the W3C Web Accessibility Initiative (WAI) and are covered by the
W3C Document License. They are used here for educational / research grounding
of remediation suggestions.

Primary sources referenced:

- WCAG 2.2 (W3C Recommendation, 2023)
  https://www.w3.org/TR/WCAG22/
- "How to Meet WCAG 2.2" quick reference
  https://www.w3.org/WAI/WCAG22/quickref/
- "Understanding WCAG 2.2"
  https://www.w3.org/WAI/WCAG22/Understanding/
- Techniques for WCAG 2.2
  https://www.w3.org/WAI/WCAG22/Techniques/
- WAI-ARIA Authoring Practices (informative, referenced where relevant)
  https://www.w3.org/WAI/ARIA/apg/

The text files in this directory are short, paraphrased summaries of the
relevant success criteria + fix guidance, written to be RAG-friendly. Each
file includes the canonical criterion identifier and a link back to the
official W3C page for deeper reading.

The retrieval layer MUST cite the canonical W3C URL rather than claiming
authorship of the underlying normative text.
