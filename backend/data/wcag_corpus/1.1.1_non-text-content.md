# 1.1.1 Non-text Content (Level A)

Canonical URL: https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html

All non-text content that is presented to the user has a text alternative that
serves an equivalent purpose. This includes images, icons, charts, and
image-based buttons or links.

## Why it matters

Screen readers cannot interpret image pixels. Without a text alternative,
blind or low-vision users lose information and may not be able to complete
tasks such as identifying a product photo or activating an icon-only
control.

## Common failures

- `<img>` without an `alt` attribute.
- Decorative images given a descriptive `alt` (should be `alt=""`).
- Icon-only buttons / links with no accessible name (no text, no
  `aria-label`, no `title`, no nested image with non-empty `alt`).
- SVG used as an image without `role="img"` plus an accessible name.
- Complex images (charts, infographics) with only a short caption.

## Fix guidance

- Meaningful images: add a concise, purposeful `alt` describing the image's
  function. For product photos, include the product name.
- Decorative images: use `alt=""` so assistive tech skips them.
- Icon-only controls: add `aria-label="Search"` (for example) or visually
  hidden text inside the button.
- Complex images: pair a short `alt` with a longer text description nearby or
  linked via `aria-describedby`.
- Inline SVG: use `<svg role="img" aria-label="...">` or `<title>` as the
  first child.
