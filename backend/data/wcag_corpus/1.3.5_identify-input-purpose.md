# 1.3.5 Identify Input Purpose (Level AA)

Canonical URL: https://www.w3.org/WAI/WCAG22/Understanding/identify-input-purpose.html

The purpose of each input field collecting information about the user can be
programmatically determined when the field serves a common purpose.

## Why it matters

When fields are tagged with the right `autocomplete` value, browsers and
assistive tech can auto-fill them, reducing cognitive load — especially
important in long checkout forms.

## Common failures

- Email / address / phone / credit-card fields with no `autocomplete`.
- Wrong `autocomplete` tokens ("off" on fields that should auto-fill).

## Fix guidance

- Use the WHATWG autofill tokens: `autocomplete="email"`, `"given-name"`,
  `"family-name"`, `"tel"`, `"street-address"`, `"postal-code"`,
  `"cc-number"`, etc.
- Combine with the right `type=` (e.g. `type="email"`, `type="tel"`).
