# 3.3.2 Labels or Instructions (Level A)

Canonical URL: https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html

Labels or instructions are provided when content requires user input.

## Why it matters

Users need to know what each field expects before they fill it in. This is
critical in checkout flows — unlabelled fields are one of the top reasons
for cart abandonment by AT users.

## Common failures

- `<input>` with no visible label and no `aria-label`.
- Only a placeholder, which disappears on focus.
- Required fields marked only by color (red asterisk) with no programmatic
  "required" indication.
- Ambiguous labels ("Name") where the page wants a specific format.

## Fix guidance

- Every input gets a `<label for>` (preferred) or an `aria-label`.
- Add visible instructions for format requirements next to the label.
- Use `aria-required="true"` and / or native `required`, and indicate
  required-ness in the visible label too (not only color).
